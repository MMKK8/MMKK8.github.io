# Politica de privacidad de HomeAssistant

Ultima actualizacion: 10 de octubre de 2026

HomeAssistant es una aplicacion de uso personal, utilizada unicamente por su propietario (kozarzewski@gmail.com). No se ofrece al publico.

## Datos a los que accede

Con la autorizacion explicita del usuario mediante OAuth de Google, la aplicacion accede a los calendarios y eventos de Google Calendar de la cuenta autorizada, solo para mostrarlos en el panel domestico de Home Assistant del propietario.

## Uso de los datos

Los datos se usan exclusivamente para esa funcion. No se venden, no se usan para publicidad y no se comparten con terceros, salvo por obligacion legal.

El uso y la transferencia de informacion recibida de las API de Google cumple la Politica de datos de usuario de los servicios de API de Google (Google API Services User Data Policy), incluidos los requisitos de uso limitado (Limited Use).

## Almacenamiento y seguridad

Los tokens de acceso y los datos del calendario se guardan unicamente en el servidor local de Home Assistant controlado por el propietario.

## Revocar el acceso

Puedes revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions
