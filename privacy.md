# Politica de privacidad de Hermes Conector

Ultima actualizacion: 5 de octubre de 2026

Hermes Conector es una aplicacion de uso personal, utilizada unicamente por su propietario (kozarzewski@gmail.com). No se ofrece al publico.

## Datos a los que accede

Con la autorizacion explicita del usuario mediante OAuth de Google, la aplicacion puede acceder a los datos de la cuenta de Google que el usuario haya autorizado (por ejemplo correo, calendario o archivos), solo para las funciones que el propio usuario solicita a su asistente Hermes.

## Uso de los datos

Los datos se usan exclusivamente para prestar esas funciones al propietario. No se venden, no se usan para publicidad y no se comparten con terceros, salvo cuando sea necesario para ejecutar la accion pedida por el usuario o por obligacion legal.

El uso y la transferencia de informacion recibida de las API de Google cumple la Politica de datos de usuario de los servicios de API de Google (Google API Services User Data Policy), incluidos los requisitos de uso limitado (Limited Use).

## Almacenamiento y seguridad

Los tokens de acceso se guardan de forma local en equipos controlados por el propietario. Los datos no se almacenan mas tiempo del necesario.

## Revocar el acceso

Puedes revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions
